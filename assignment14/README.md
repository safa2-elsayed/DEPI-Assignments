Smart Hotel Booking - Flutter App

A cross-platform Flutter application for hotel booking with interactive features including card expansion, tab switching, price range selection, and animated buttons. Built with BLoC state management for clean architecture.

Features

🎯 Core Features

•
Hotel Card Expansion: Tap the hotel card to expand and view detailed information

•
Tab Switching: Switch between "Offers" and "Guest Reviews" with smooth animations

•
Price Range Slider: Interactive price slider with input field for custom price selection

•
Bounce Animation: Book Now button with bounce animation feedback

•
Bottom Navigation: Navigation bar with Home, Bookings, Favorites, and Profile tabs

🏗️ Architecture

•
State Management: BLoC (Business Logic Component) pattern

•
Clean Architecture: Separation of concerns with events, states, and bloc layers

•
Cross-Platform: Works on iOS, Android, and other Flutter-supported platforms
